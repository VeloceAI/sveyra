# SVEYRA Web

Frontend workspace for the personal style, wardrobe, outfit, avatar, and shopping experiences.

Framework decision is intentionally isolated here. The expected default is Next.js with React Three Fiber for browser 3D.

## Product Surfaces

- Today outfit decision
- Wardrobe capture and organization
- Style profile onboarding
- Fit and measurement profile
- Avatar and virtual try-on
- Shopping recommendations
- Conversational stylist
